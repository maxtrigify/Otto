# Code of conduct

Otto follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the work. Harassment or
personal attacks aren't tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour privately to the maintainers through
[GitHub security advisories](https://github.com/maxtrigify/Otto/security/advisories/new)
or by contacting the repository owner directly. Reports are handled confidentially.
